## 📌 Projetos em Destaque

### 🛒 TechStore — E-commerce Demo
<p align="left">
  <img src="https://img.shields.io/badge/Web-React-blue?style=flat-square&logo=react" alt="React">
  <img src="https://img.shields.io/badge/Banco_de_Dados-Supabase-green?style=flat-square&logo=supabase" alt="Supabase">
</p>

Um projeto demonstrativo de habilidades em desenvolvimento web. O objetivo é mostrar o domínio de técnicas modernas de frontend combinadas com a integração de um banco de dados. 

- **Funcionalidades Implementadas:**
  - Listagem dinâmica de produtos com imagens.
  - Sistema de filtro por categoria.
  - Ícone e aba funcional de carrinho de compras.
  - Tela de login simbólica (interface visual sem autenticação real).
  - Adição de produtos de forma local e integrada via banco de dados.
- **Notas e Observações:** Este site **não** é uma loja real e não possui integração comercial ou dados de clientes verdadeiros. Todos os dados, imagens e funcionalidades são fictícios, servindo estritamente para demonstração técnica e portfólio.
- **Acesso ao código:** Todos os arquivos referentes a este projeto estão na pasta `Demo-Loja/`.
