# TechStore - E-commerce Demo

Este site é um projeto demonstrativo de habilidades em desenvolvimento web. Não se trata de uma loja real, nem possui integração comercial ou dados de clientes verdadeiros. O objetivo é mostrar técnicas modernas de frontend, e integração com banco de dados.

## Tecnologias Utilizadas

- **React**: Biblioteca principal para construção da interface de usuário.
- **TypeScript**: Tipagem estática para maior segurança e produtividade.
- **Vite**: Ferramenta de build e desenvolvimento rápido para projetos frontend.
- **Tailwind CSS**  : Framework de estilos utilitário para design responsivo e moderno.
- **Supabase**: Backend como serviço, utilizado para simular banco de dados e autenticação "Conhecimentos apenas basicos".
- **Lucide Icons**: Ícones modernos para interface.

## Funcionalidades Demonstradas

- Listagem de produtos com imagens dinâmicas
- Filtro por categoria
- Ícone do carrinho "e aba de Carrinho"
- Tela de login simbólica (sem autenticação real)
- Adição de produtos localmente e via banco de dados

## Observações

Este projeto não deve ser utilizado para fins comerciais. Todos os dados, imagens e funcionalidades são fictícios e servem apenas para fins de demonstração técnica.
